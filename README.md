# Найди кота

Редактор учебных игр Гальмиз Марии Александровны. Откройте **index.html** в современном браузере. Для работы не нужны установка, сборка и интернет.

Для загрузки новых GIF из онлайн-каталога Noto нужен интернет. Уже выбранные GIF и все встроенные фоны работают без сети.

## Анимации, GIF и готовые фоны

В «Героях» каждый из восьми эффектов автоматически проигрывается на выбранном персонаже при смене эффекта, цвета, длительности, повторов или итогового действия. Через короткую паузу герой возвращается в исходное состояние. «Повторить эффект» позволяет посмотреть его ещё раз. Предпросмотр не засчитывает героя найденным и не меняет проект; готовая игра использует тот же механизм анимации.

**Каталог GIF Noto** содержит 881 анимированный эмодзи из [официальной библиотеки Google](https://googlefonts.github.io/noto-emoji-animation/), с поиском по русским названиям и английским ключевым словам, категориями и страницами по 24 элемента. Каталог доступен в «Героях» и рядом с загрузкой картинок — для фона, вопросов и экранов. При выборе GIF скачивается, оптимизируется без потери кадров и встраивается в JSON/HTML. Ошибка сети не меняет проект; можно повторить выбор или загрузить GIF с компьютера.

Для GIF Noto сохраняется указание источника и лицензии CC BY 4.0. В готовой игре, использующей эти анимации, есть небольшой раскрывающийся пункт «Источники анимаций». Он не содержит авторскую надпись редактора.

В «Дизайне» появились **шесть самостоятельных SVG-фонов**, созданных для редактора: городские крыши, город у канала, большая библиотека, сад и оранжерея, деревня с мельницей, город астрономов. У каждого три палитры: контурная, природная и тёплая бумага — всего 18 вариантов. Выбор фона сохраняет размещение героев и задания; его можно отменить. В рисунки не встроены коты, которые не реагировали бы на нажатие.

При подготовке фонов изучены примеры [100 hidden cats](https://store.steampowered.com/app/1587560/100_hidden_cats/) и «100 Котов: Мировой тур». Использован общий принцип подробного контурного рисунка; игровые изображения из этих игр в редактор не включены.

## Создание игры

1. В «Дизайне» загрузите фон.
2. В «Героях» добавьте свои изображения, GIF или выберите персонажей из встроенной базы эмодзи с поиском на русском языке. До 100 героев. Картинки автоматически оптимизируются при загрузке.
3. Перетащите героев на сцене. Зелёный квадрат меняет размер, круг — поворот. Shift сохраняет пропорции. Красный крестик удаляет картинку/героя; удаление можно отменить.
4. Нажмите на героя: откроются его задание и окно живого предпросмотра. Изменения текста, вариантов ответов и оформления сразу отражаются в окне.
5. В таблице заданий для каждого героя есть тип задания и колонки **Вопрос | Ответ**. Число заданий всегда равно числу героев. При добавлении героя появляется пустое задание, при дублировании — копия его задания, при удалении удаляется связанное задание. Заголовков вроде «Живой мир» или «Немного математики» нет.
6. Для просмотра титульного экрана выберите «Титульный экран» над сценой. В этом же списке есть игровое поле, задание, победа и поражение.
7. В «Сложности» задайте жизни, штрафы и таймер; в «Звуках» — аудио. Кнопка «Тест» запускает полноценную игру.
8. «Сохранить проект» скачивает JSON для дальнейшего редактирования. «Скачать HTML» создаёт самостоятельную игру.

Надпись «Все права защищены и принадлежат Гальмиз Марии Александровне» находится **только в подвале редактора**. В игре и в её коде для Genially этой надписи нет.

## Genially

Откройте **Genially** в верхней панели. Код появляется сразу; вводить URL для встроенного варианта не нужно.

- **Встроенная игра** — iframe с автономным HTML в `srcdoc`. Собственные стили игры отделены от оформления платформы, у кнопок есть явные отступы.
- **Полный HTML-код** — содержимое самостоятельной HTML-игры.
- **Iframe по HTTPS-ссылке** — код для игры, опубликованной на GitHub Pages или другом HTTPS-хостинге.

**Облегчить код** оптимизирует ресурсы, использует минифицированный игровой движок, заранее преобразует формулы в MathML и обновляет код прямо в окне Genially. Размер до и после показан над полем. Эта кнопка не скачивает отдельный файл вместо изменения кода.

**Копировать код** работает с обоими форматами. Если браузер запрещает доступ к буферу, код выделяется и предлагается Ctrl/Cmd + C. Кнопка не сообщает об успешном копировании при отказе браузера.

Genially может ограничивать `srcdoc` или выполнение вставленных скриптов. В таком случае выберите вариант по HTTPS-ссылке: скачайте HTML, загрузите на GitHub Pages и укажите адрес файла. Это ограничение внешней платформы, а не требование редактора. [Инструкция Genially по вставке внешнего контента](https://help.genially.com/en_us/embed-a-google-sheets-chart-in-genially-Skq3qwr3j).

## Формулы

Используйте LaTeX из приложенной шпаргалки:

```text
Вычислите $\frac{3}{4}+\frac{1}{4}$
$x^{10}+a_{n+1}$
$\sqrt[n]{a}$
$\sum_{i=1}^{n} i$
$\lim_{x\to 0} f(x)$
$90^\circ$, $a\parallel b$, $\overline{AB}$
$$\begin{cases}x+y=5\\x-y=1\end{cases}$$
```

`$...$` — формула в строке, `$$...$$` — отдельной строкой. Также поддерживаются `\(...\)` и `\[...\]`. Формулы работают в вопросах, ответах, пояснениях и текстах экранов, в предпросмотре и экспорте. Рядом с таблицей есть раскрывающаяся подсказка с примерами.

Все 44 выражения из `Shpargalka.pdf` проверены. Используется встроенный KaTeX 0.16.22 с выводом в MathML; сеть и внешние шрифты не нужны. Неподдерживаемая или ошибочная команда показывается с красной отметкой, а не исчезает. Это отображение формул, не распознавание формул с фотографии и не система автоматического доказательства равенства выражений. [Поддерживаемый синтаксис KaTeX](https://katex.org/docs/supported).

## Изображения и GIF

- PNG/JPG/WEBP автоматически уменьшаются до 1600 px по длинной стороне; собственные герои — до 512 px. Пробуется WebP, сохраняется только вариант меньшего объёма.
- SVG очищаются от скриптов, внешних ссылок и лишних метаданных.
- GIF оптимизируются без потери анимации: удаляются комментарии, сохраняются кадры, паузы и зацикливание. Размеры и палитра анимации не перекодируются, поэтому GIF без лишних данных может не уменьшиться.
- Крестики есть у картинок в панелях, у героев на сцене и у картинок в предпросмотре задания/экранов. В экспортированной игре редакторских крестиков нет.
- База содержит 1941 эмодзи с русскими названиями и категориями. Внешний вид эмодзи зависит от устройства.

## Сохранение и публикация

Проект сохраняет ресурсы внутри JSON. Автосохранение работает через IndexedDB; если браузер ограничивает его для локальных файлов, сохраняйте JSON вручную. История содержит 70 действий. Ctrl/Cmd + Z отменяет, Ctrl/Cmd + Shift + Z повторяет.

Для публикации редактора достаточно одного **index.html** в корне репозитория. GitHub Pages можно включить в настройках репозитория. Экспортированные игры загружаются отдельно; публикация редактора не публикует автоматически ваши учебные проекты.

Старые JSON-проекты загружаются. Если одно задание было назначено нескольким героям, для них создаются независимые копии. Старые несвязанные вопросы не включаются в новую таблицу: храните исходный JSON как резервную копию.

## Разработка и проверки

Зависимости нужны только для разработки:

```sh
npm install
npm run build
npm test
```

`build` обновляет встроенную минифицированную версию движка для облегчённого экспорта. После изменения `core-script` выполняйте сборку. `tests/core.test.mjs` перенаправляет на актуальную регрессионную проверку.

Тесты используют jsdom: проверяют интерфейс и обработчики, формулы, копирование, код для Genially, синхронизацию героев/заданий и запуск экспортированной игры. Обработка растрового изображения проверяется с имитацией canvas. Это не визуальные тесты реального браузера или Genially: подключённого браузера в рабочей среде не было.

Сведения о сторонних компонентах находятся в `THIRD_PARTY_NOTICES.md` и встроены в файл редактора.
